# Luminous

الموقع التعريفي لشركة **Luminous for Food Industry** — موقع صفحة واحدة (One-Page) ثنائي اللغة (عربي/إنجليزي) لعرض هوية الشركة ومنتجاتها.

## هيكلية المشروع

```
Luminous/
├── index.html                  # الصفحة الرئيسية (كل الأقسام)
├── assets/
│   ├── css/style.css           # التنسيقات + الحركة (Animations)
│   ├── js/main.js              # تبديل اللغة AR/EN + قائمة الموبايل + Scroll Reveal
│   ├── links.txt                # روابط انستغرام وفيسبوك المصدر
│   ├── luminous logo.pdf        # اللوغو الأصلي (مصدر)
│   └── images/
│       ├── logo.png             # اللوغو (مُفرّغ الخلفية) — من ملف الـ PDF
│       ├── logo-mark.png        # أيقونة ورقة الكاكاو فقط (مقتطعة من اللوغو)
│       ├── product-*.jpg        # صور المنتجات (7 نكهات)
│       ├── piano-*.jpg          # صور خط بيانو
│       ├── gallery-*.jpg        # صور معرض/إعلانات
│       └── about-brochure.jpg   # صورة البروشور
```

## اللغة الثنائية

كل نص بالموقع موجود بسمتَي `data-ar` و `data-en` على نفس العنصر. زر تبديل اللغة أعلى الصفحة يبدّل الاتجاه (`rtl`/`ltr`) والخط والنصوص فورًا، ويحفظ الاختيار في `localStorage`.

## الهوية البصرية

الألوان (بني الكاكاو، الكريمي، الذهبي) مأخوذة مباشرة من عينات لون اللوغو وصور المنتجات. أيقونة ورقة الكاكاو من اللوغو تُستخدم كعنصر حركي هادئ (تمايل خفيف) في أماكن متعددة بدل رسم أشكال جديدة.

## إضافة/تحديث الميتيريال

- صور جديدة: ضعها في `assets/images/` ثم أشِر إليها من `index.html`.
- فيديو: أضِف مجلد `assets/videos/` وعنصر `<video>` عند الحاجة.
- تحديث رقم الهاتف/الروابط الاجتماعية: عدّل قسم `#contact` والفوتر في `index.html` (والرقم مستخدم أيضًا في روابط واتساب `wa.me/201127489999`).

## المعاينة محلياً

افتح `index.html` مباشرة بالمتصفح، أو شغّل سيرفر بسيط:

```bash
npx serve .
```
